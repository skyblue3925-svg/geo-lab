# Case Mode Usage

## 목적
여행지리 수업에서 `내러티브 + 실제 사례 앵커 + 정량 실험`을 한 번에 수행합니다.

## 포함 사례 (6개)
1. Delta Gateway: Sediment vs Overtourism
2. Cliffline Route: Coastal Retreat and Safety
3. Fjord Corridor: Climate Risk and Route Choice
4. Limestone Icon: Karst Heritage Under Visitor Pressure
5. Volcanic Geo-Trail: Access Value vs Hazard Windows
6. Desert Canyon Route: Flash Flood Risk and Seasonal Access

## 로컬서버 실행
1. 터미널에서 프로젝트 폴더로 이동
   `cd C:\Users\HANSOL\OneDrive\Desktop\Geo-lab`
2. 서버 실행
   `.\.venv\Scripts\python.exe -m streamlit run app.py`
3. 브라우저에서 `http://localhost:8501` 접속
4. 좌측 페이지에서 `6_🧭_케이스_모드` 선택

## 수업 운영 흐름 (45~50분)
1. Case Mode에서 사례 1개 선택 후 Narrative/Timeline/Evidence Pack 확인.
2. `Load baseline DEM to Research Lab` 클릭.
3. Research Lab에서 profile/slope/hypsometric 증거 2개 이상 확보.
4. Case Mode로 돌아와 A/B 정책 실험 실행.
5. 차이 맵과 지표(기복량, 평균고도, delta ratio)로 CER 작성.
6. 필요 시 `Load climate hint to session` 후 Climate Lab에서 계절성 해석 보강.

## 학생 제출 최소 산출물
- 근거 그래프 2개 이상 (Research Lab)
- A/B 수치 비교 표 1개
- Difference map 캡처 1개
- CER 문단 1개 (숫자 근거 2개 이상 포함)
- 정책 메모 1쪽

## 교사용 운영 팁
- Evidence Pack의 수치는 기준 프레임으로 쓰고, 지역 통계가 있으면 교체해서 사용합니다.
- 채점은 정답보다 근거-논리 연결을 우선합니다.
- 불확실성이 큰 사례(기후/재난)는 반론과 한계를 CER에 반드시 포함시킵니다.
