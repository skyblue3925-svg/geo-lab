# 지형 형성 이미지 기반 애니메이션 제작 계획

## 목표

학생이 각 지형의 형성 원인과 과정을 애니메이션으로 이해하도록, 생성 이미지 기반 스토리보드와 기존 3D 지형 렌더러를 연결한다.

## 현재 완료

- 지형별 4패널 원본 이미지 38개 생성.
- 지형별 GPT Image 프롬프트 원문 38개 저장.
- 원본 4패널 이미지를 단계별로 잘라 약 60프레임 GIF로 보간.
- 석호와 해안사구는 사용자 피드백 기준으로 재생성 후 GIF 재빌드.
- Gallery의 기존 시네마틱 목록에 `storyboard_smooth/metadata.json`을 자동 병합.
- Gallery 3D 미리보기에서 `생성 이미지 단계` 텍스처를 선택할 수 있도록 연결.
- 기존 카메라 모션(`오빗`, `패닝`)을 사용해 애니메이션 중 카메라 방향 전환 가능.

## 산출물 경로

- 원본 이미지/프롬프트: `output/terrain-animation-assets/`
- 부드러운 GIF: `assets/cinematic/storyboard_smooth/`
- GIF 메타데이터: `assets/cinematic/storyboard_smooth/metadata.json`
- 생성 스크립트: `scripts/build_storyboard_smooth_animations.py`

## 구현 전략

1. 이미지 기반 2D 애니메이션
   - 4패널 스토리보드를 동일 크기의 단계 이미지로 분리한다.
   - 단계 사이를 cross-fade 보간하고, 각 단계에 약한 pan/zoom을 넣는다.
   - 수업용 재생성을 위해 GIF와 메타데이터를 자동 생성한다.

2. 기존 3D 렌더러 연동
   - Gallery의 위성 느낌 렌더링에서 생성 이미지 패널을 표면 텍스처로 사용한다.
   - 단계 슬라이더 값에 맞춰 4개 패널 중 가까운 단계를 선택한다.
   - 카메라 연출은 기존 `오빗`/`패닝` 모드를 활용해 재생 중 시점 변화를 제공한다.

3. 다음 개선
   - Plotly 프레임별로 텍스처도 함께 바뀌도록 `texture_keyframes`를 추가한다.
   - 지형별 카메라 모션 프리셋을 문서화해 석호, 사구, 피오르처럼 방향성이 중요한 지형의 시점을 자동 추천한다.
   - GIF 외에 MP4/WebM 내보내기를 추가해 파일 크기와 재생 품질을 개선한다.
