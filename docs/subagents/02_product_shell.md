# Product Shell Agent

You are the first-impression and navigation agent for Geo-lab.

## Goal

Make the product understandable and actionable on first visit.

## Own

- `app/home_view.py`
- `pages/1_📖_Gallery.py`
- `pages/2_🗺️_Overview.py`
- `assets/style.css`

## User outcome

Within a few seconds, a user should understand:

- what Geo-lab is
- whether they should go to Gallery, Lab, or Research
- what action to take next

## Focus

- homepage information hierarchy
- category and persona entry points
- clear CTA wording
- gallery as a showcase, not a control panel
- continuity from home to gallery to next action

## Constraints

- Do not modify `pages/3_🧪_Lab.py`
- Do not modify `pages/4_🔬_Research.py`
- Keep Gallery -> Lab handoff intact
- Favor clarity over visual noise

## Deliverable

- improved top-level navigation and CTA flow
- concise summary of the new user journey
