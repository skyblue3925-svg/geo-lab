# Travel Geography Narrative Pack (6 Topics)

## Course Storyline

당신의 반은 "여행지리 탐사단"이 되어 가상의 지역 `아라해 권역`을 조사한다.
탐사단의 임무는 단순 관광 코스 제안이 아니라, 지형·기후·교통·지역사회 데이터를 함께 읽고
"지속가능한 여행 계획"을 최종 제안하는 것이다.

수업의 모든 장면은 같은 질문으로 연결된다.
`좋은 여행은 누구에게, 어떤 조건에서, 얼마나 오래 가능한가?`

---

## Topic 1. 하천 지형과 유역의 이야기

### 장면
산지에서 출발한 작은 물줄기가 평야를 지나 바다로 흘러가며, V자곡·곡류·삼각주를 만든다.
탐사단은 "물길의 선택"이 지역의 삶을 어떻게 바꾸는지 추적한다.

### 탐구 질문
- 왜 어떤 곳은 골짜기가 깊어지고, 어떤 곳은 퇴적이 쌓일까?
- 유역 상류의 변화가 하류 정주·농업·관광에 어떤 영향을 주는가?

### 계산/실험
- 조절 변수: 침식 강도, 융기 속도, 시간
- 기록 지표: 최대/평균 고도 변화, 수역 분포 변화
- 비교 방식: 동일 초기지형에서 변수 1개만 바꿔 A/B 실험

### Geo-lab 활용
- `pages/1_📖_Gallery.py`: 지형 유형 관찰
- `pages/3_🧪_Lab.py`: 변수 실험

### 산출물
- "상류-중류-하류" 3단 구조 설명 카드
- 캡처 2장 + 원인-결과 문장 3개

## Topic 2. 해안 변화와 위험의 이야기

### 장면
파도와 조류가 절벽을 깎고, 사취와 석호를 만들고, 육지의 경계를 바꾼다.
탐사단은 해안 마을 축제 코스를 설계해야 하지만, 침식 위험도 함께 제시해야 한다.

### 탐구 질문
- 같은 해안이라도 왜 어떤 해변은 넓어지고, 어떤 해변은 사라질까?
- 관광 동선과 재난 취약 구역은 어떻게 겹치는가?

### 계산/실험
- 조절 변수: 파랑/해안 에너지, 시간, 해수면 조건
- 기록 지표: 침식 우세 구역, 퇴적 우세 구역, 위험도 구역도

### Geo-lab 활용
- `pages/1_📖_Gallery.py`: 해안 지형 사례
- `pages/4_🔬_Research.py`: 시나리오 비교

### 산출물
- 1페이지 "해안 이용-보전" 제안서
- 위험 구역 표시 지도 1개

## Topic 3. 기후-인간 상호작용의 이야기

### 장면
기후가 바뀌면서 같은 여행지도 계절마다 완전히 다른 얼굴을 보인다.
탐사단은 지역의 기후 리스크를 분석하고, 인간 개입(관리/대응)의 효과를 검토한다.

### 탐구 질문
- 기후 조건 변화가 지형·수문·관광활동을 어떻게 동시 변화시키는가?
- "개입 없음"과 "개입 있음"의 결과 차이는 얼마나 큰가?

### 계산/실험
- 조절 변수: 기후 강도, 개입 수준
- 기록 지표: 위험 점수, 변동 폭, 안정화 효과

### Geo-lab 활용
- `pages/5_☁️_Climate.py`: 기후 모듈
- `pages/3_🧪_Lab.py`: 개입 시나리오 실험

### 산출물
- 정책 메모(위험, 근거, 대응, 한계)

## Topic 4. 오버투어리즘과 수용력의 이야기

### 장면
유명 관광지가 SNS로 급확산되며 방문객이 폭증한다.
탐사단은 "얼마나 많이"가 아니라 "얼마까지 가능"한지를 계산해 제시해야 한다.

### 탐구 질문
- 수용 한계를 넘는 순간, 무엇이 먼저 무너지나?
- 방문객 규제는 지역경제와 주민생활 사이에서 어떤 균형을 만들까?

### 계산 모델(수업용)
- `혼잡지수 = 방문객수 / 수용한계`
- `환경부하지수 = 혼잡지수 × 성수기계수 × 체류계수`
- `주민불편지수 = 환경부하지수 × (1 - 관리강도)`

### 활동
- 조별로 성수기/비수기 시나리오를 나눠 계산
- 같은 방문객 수라도 관리강도 변화에 따라 지수 차이 비교

### 산출물
- "허용 가능한 방문량" 권고안 (수치 포함)

## Topic 5. 교통수단과 탄소발자국의 이야기

### 장면
같은 여행지라도 이동 방식이 다르면 탄소배출이 크게 달라진다.
탐사단은 "가성비"가 아니라 "탄소 대비 경험"을 기준으로 경로를 다시 설계한다.

### 탐구 질문
- 항공·철도·버스의 조합이 총배출량에 어떤 차이를 만드는가?
- 이동거리보다 더 큰 영향을 주는 변수는 무엇인가?

### 계산 모델(수업용)
- `총배출량 = Σ(거리 × 교통수단 배출계수 × 인원)`
- `1인당배출량 = 총배출량 / 인원`
- `체류효율지수 = 체류일수 / 1인당배출량`

### 활동
- 동일 예산으로 2개 경로 설계
- "최저탄소"안과 "균형"안을 모두 제출

### 산출물
- 경로 비교표(배출량·비용·체류효율)

## Topic 6. 기후위험 기반 의사결정의 이야기

### 장면
출발 직전, 폭염·호우·태풍 예보가 동시에 올라온다.
탐사단은 여행 취소/강행이 아니라, 위험을 수치화해 대안 경로를 의사결정해야 한다.

### 탐구 질문
- 위험 임계값은 누가, 어떤 근거로 정해야 하는가?
- 위험 회피가 비용 증가를 만들 때, 어떤 기준으로 선택할까?

### 계산 모델(수업용)
- `기후위험점수 = 0.4×폭염 + 0.3×호우 + 0.3×태풍`
- `의사결정점수 = 기후위험점수 - 대응역량점수`
- 임계값 예시: `의사결정점수 >= 70`이면 일정 변경

### 활동
- 동일 목적지에서 3개 일정안(원안/우회/취소대체) 작성
- 각 안의 위험·비용·교육적 가치 비교

### 산출물
- 최종 의사결정 보고서 1장

## Final Mission (종합 수행)

탐사단은 6개 주제 데이터를 통합해 `지속가능 여행 설계안`을 제출한다.

필수 포함 요소:
1. 지형·기후 근거 2개 이상
2. 정량 계산표 2개 이상
3. 지역사회 영향(주민/환경/관광객) 균형 판단
4. "왜 이 선택을 했는가"에 대한 반론 대응 문장 2개
