# Geo-lab World Terrain Atlas Prompt

Design a "World Terrain Atlas" section for Geo-lab that sits between a high-school lesson catalog and a higher-ed research portal.

Product goals:
- Make global landform examples feel concrete and teachable, not encyclopedic.
- Connect each landform to one representative world case students may recognize on a real map.
- Keep the main experience classroom-first for high school, while hinting at deeper academic use.

Audience split:
- High school teachers: want a world example they can point to in class immediately.
- High school students: need one memorable place, one key process, one question.
- Higher ed users: want a clean bridge toward case comparison and deeper explanation, but not on the main card.

Structure:
1. Atlas hero:
- Title around "세계 대표 지형 사례"
- Short copy explaining that Geo-lab links process-based landform learning to real places on Earth

2. Case cards:
- Large thumbnail
- Korean case title
- Region / location label
- One-sentence classroom hook
- 2-3 process chips
- One student question
- CTA 1: "이 사례 보기"
- CTA 2: "Lab 수업으로 열기"

3. Categories:
- River systems
- Delta / estuary
- Glacial landscapes
- Karst
- Coastal landscapes
- Volcanic landscapes

4. Visual direction:
- Not dark sci-fi
- Feels like an intentional museum atlas + modern classroom tool
- Use map-like neutrals, sediment browns, water blues, muted tectonic reds
- Avoid clutter and avoid generic SaaS panels

Cases to foreground:
- Death Valley alluvial fan
- Alpine V-shaped valley
- Mississippi meander plain
- Nile delta
- Norway fjord
- Guilin tower karst
- Hawaii shield volcano
- Pacific uplifted coastal cliff / marine terrace

Interaction rules:
- Clicking a case should switch the current gallery preset to the matching landform
- A secondary CTA should hand off to Lab with the matching teaching preset
- Show only one key process message per card

Copy tone:
- Concrete, classroom-friendly, not academic-jargon-heavy
- Every card should answer:
  - Where is this?
  - What process dominates?
  - Why should a student care?
