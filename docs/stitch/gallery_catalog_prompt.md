# Geo-Lab Stitch Prompt: High School Gallery Catalog

목표:
- Gallery는 고등학교 수업용 예시 카탈로그처럼 보여야 한다.
- 첫 인상은 설정 패널이 아니라 `수업에서 바로 쓸 지형 카드 모음`이어야 한다.
- 연구/전문가용 조작은 기본 화면에서 숨기고, 필요할 때만 고급 미리보기로 연다.

원칙:
- 카드에 `수업 포인트`, `난이도`, `관찰 질문`이 함께 보여야 한다.
- CTA는 충돌하지 않게 정리한다: `이 예시 선택`과 `Lab에서 수업 시작`의 역할이 분명해야 한다.
- 기본 보기 모드는 `수업용 카탈로그`, 고급 조작은 별도 모드 또는 접힌 패널로 분리한다.
- Gallery에서 Research 냄새가 나면 안 된다. 이 페이지는 철저히 고등학교 수업용이어야 한다.

원하는 섹션:
1. Hero
   - 헤드라인: 수업용 예시 카탈로그
   - 서브카피: 지형 하나를 고르고 바로 핵심 장면을 미리 본다.
2. Card grid
   - 썸네일 중심 카드
   - 수업 포인트
   - 난이도 배지
   - 짧은 설명
3. Selected lesson panel
   - 관찰 질문
   - 추천 수업 흐름
   - Lab 수업 시작 CTA
4. Preview zone
   - 기본은 preset 기반 미리보기
   - 형성 단계만 가볍게 조절
5. Advanced preview
   - 해상도/카메라/텍스처/재생 엔진은 따로 숨겨 제공

비주얼 톤:
- 박물관형 쇼케이스보다 `교실 앞 시연용 카탈로그`
- 카드가 이미지 중심으로 떠 있어야 함
- 색은 교육용 메인 브랜드를 따르되, 너무 무겁거나 연구용처럼 보이지 않게

피해야 할 것:
- 카드보다 설정 패널이 먼저 보이는 레이아웃
- 같은 의미의 CTA가 여러 번 나오는 것
- 첫 화면에서 고급 3D 컨트롤이 한꺼번에 노출되는 것
