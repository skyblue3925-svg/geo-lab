# Geo-Lab Stitch Prompt: High School Home

목표:
- 메인 홈은 고등학교 교사와 학생이 바로 쓰는 수업용 홈페이지여야 한다.
- 대학·연구·교수용 기능은 메인에서 직접 노출하지 않고 별도 포털로 분리한다.

원칙:
- 첫 화면에서 "이 사이트는 고등학교 지형 수업용"이라는 메시지가 명확해야 한다.
- 첫 CTA는 2개만 강하게 둔다: 교사용 시작, 학생 탐구 시작.
- Research는 메인 카드와 같은 위상으로 두지 않는다. 별도 secondary gateway로만 둔다.
- 정보보다 흐름을 먼저 보여준다: Gallery 카탈로그 → Lab teacher mode → Lab student mode.

원하는 섹션:
1. Hero
   - 헤드라인: 고등학교 지형 수업에서 바로 쓰는 실험형 홈
   - 서브카피: 모범 사례 선택, 교사용 시연, 학생 탐구를 한 흐름으로 묶는다.
2. Primary CTA cards
   - 교사용 시작
   - 학생 탐구 시작
3. 한 차시 운영 흐름
   - Warm-up / Explain / Explore 3단계 카드
4. 현장성 근거
   - 설명 없는 첫 진입
   - 수업용 캡션 중심
   - 모범 사례에서 바로 시연
5. Separate gateway
   - 대학·연구·교수 사용자는 별도 포털로 이동

비주얼 톤:
- 과장된 SaaS보다 차분한 교육 도구 느낌
- 짙은 남색 계열 hero, 밝은 카드, 높은 가독성
- 교실용이라 버튼과 계층이 선명해야 함

피해야 할 것:
- 연구 기능을 메인 홈의 동등한 첫 CTA로 노출
- 텍스트 과다
- 카드가 너무 많아 첫 진입이 복잡해지는 구성
