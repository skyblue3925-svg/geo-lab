# 고등학교 지형 형성 애니메이션 가이드

## 목적

이 문서는 Geo-lab의 지형 애니메이션을 `고등학생이 수업 시간에 이해할 수 있는 수준`으로 설계하기 위한 기준을 정리한다.

핵심은 아래 두 가지다.

1. 애니메이션이 단순히 예쁜 3D 재생이 아니라, `내적 작용`과 `외적 작용`의 순서를 읽게 해야 한다.
2. 학생이 교과서 설명에 `덧붙여` 활용할 수 있도록, 장면마다 `무엇이 먼저이고 무엇이 결과인지`가 분명해야 한다.

## 고등학교 수업 기준으로 반드시 보여야 하는 내용

Geo-lab이 고등학생 대상 수업 보조 도구로 쓰이려면 아래 요소가 화면에서 직접 읽혀야 한다.

- 외적 작용: 풍화, 침식, 운반, 퇴적
- 내적 작용: 융기, 침강, 단층, 습곡, 화산 활동
- 대표 지형: V자곡, 선상지, 삼각주, 곡류 하천, U자곡, 해식애, 카르스트, 습곡 산지
- 과정 순서: `지형 골격 형성 -> 표면 작용 집중 -> 퇴적/조정 -> 대표 형상 정리`

이 기준을 만족하려면 장면마다 하나의 우세 작용이 보여야 한다. 여러 과정을 한 장면에 동시에 강조하면 학생이 원인과 결과를 분리해서 읽기 어렵다.

## 수업용 품질 기준

### 학생용

- 한 애니메이션은 4단계 이내로 제한한다.
- 단계 제목은 명사보다 동사형으로 잡는다.
  - 예: `하천이 바닥을 깎기 시작함`
  - 비권장: `하천 침식 단계`
- 단계마다 하나의 핵심 질문만 붙인다.
- 카메라는 해당 지형이 가장 잘 드러나는 방향으로 고정하거나 매우 약하게만 움직인다.
- 오버레이는 한 번에 하나만 보여준다.

### 교사용

- 학생용 4단계를 유지하되, 교사용에서는 `오버레이 선택`, `우세 작용 순위`, `오해 포인트`를 추가한다.
- 설명 문장은 교과서 문장을 바꾸어 말하는 수준이어야 한다.
- 결과만 설명하지 말고 `왜 이 단계에서 이 작용이 우세한지`를 함께 말해야 한다.

## 금지해야 할 연출

- 뒤에서 보는 시점 때문에 지형 형성 방향이 안 보이는 카메라
- 보간만 부드럽고 과정 설명은 없는 재생
- 침식과 퇴적을 색만 다르게 칠하고 원인 설명이 없는 장면
- `진행률 70%`처럼 과정이 아닌 퍼센트만 보여주는 UI
- 학생 모드에서 수치와 통계를 너무 많이 보여주는 구성

## 프롬프트 작성 기본 템플릿

아래 템플릿은 Geo-lab stage 설계, LLM 기반 설명 생성, 외부 애니메이션 도구 지시문에 공통으로 사용할 수 있다.

```text
역할:
너는 고등학교 지형 단원의 수업 보조 애니메이션 설계자다.

목표:
학생이 지형의 최종 모양만 보는 것이 아니라, 어떤 작용이 어떤 순서로 우세해지며 현재 지형이 만들어졌는지 이해하게 한다.

학습 대상:
고등학생(처음 배우는 수준)

지형:
{landform_name}

핵심 개념:
{core_processes}

반드시 포함할 과정:
{required_processes}

금지:
- 결과만 빠르게 보여주기
- 한 장면에 여러 핵심 과정을 동시에 강조하기
- 뒤에서 보는 카메라
- 설명 없는 과도한 카메라 회전

출력 형식:
1. 4단계 이내의 스토리보드
2. 각 단계의 우세 작용
3. 각 단계에서 보여줄 오버레이 1개
4. 학생용 한 줄 설명
5. 교사용 설명 포인트
6. 학생 질문 1개

추가 요구:
- 단계 전환은 시간 비율이 아니라 과정 전환을 기준으로 한다.
- 카메라는 학생이 지형 형성 방향을 읽기 쉬운 쪽에서 본다.
```

## 애니메이션 제작 명령 템플릿

Geo-lab 내부 명령이나 외부 제작 파이프라인에 넘길 때는 아래 같은 구조를 권장한다.

```yaml
audience: high_school
mode: student
landform: alluvial_fan
view_intent: front_from_basin
camera_rule:
  movement: minimal
  must_show:
    - mountain_exit
    - fan_spread
process_sequence:
  - id: stage_1
    title: 산지에서 공급이 늘어남
    dominant_process: weathering_and_transport_supply
    overlay: tectonic
    teacher_note: 산지 출구 이전에는 경사가 급하고 재료 공급이 많다.
    student_caption: 산지에서 내려온 물질이 많이 모이는 단계입니다.
    question: 왜 산지 출구가 선상지의 시작점일까요?
  - id: stage_2
    title: 좁은 골짜기에서 운반이 집중됨
    dominant_process: transport
    overlay: transport
    teacher_note: 유로가 좁고 속도가 빨라 운반력이 유지된다.
    student_caption: 물질이 아직 쌓이지 않고 앞으로 이동합니다.
    question: 아직 퇴적보다 운반이 우세한 이유는 무엇일까요?
  - id: stage_3
    title: 출구에서 속도가 줄며 퇴적 시작
    dominant_process: deposition
    overlay: deposition
    teacher_note: 산록을 벗어나며 경사가 줄어 부채꼴 퇴적이 시작된다.
    student_caption: 흐름이 약해져 물질이 퍼지며 쌓입니다.
    question: 왜 퇴적은 하천 안보다 출구 부근에서 더 뚜렷해질까요?
  - id: stage_4
    title: 부채꼴 지형이 정리됨
    dominant_process: deposition_and_distributary_spread
    overlay: change
    teacher_note: 유로 분산과 반복 퇴적으로 선상지 전면이 넓어진다.
    student_caption: 여러 번의 퇴적이 겹치며 선상지 모양이 완성됩니다.
    question: 선상지는 침식 지형인가요, 퇴적 지형인가요?
quality_gate:
  - 산지 출구가 시각적으로 분명해야 한다
  - 퇴적 구역이 녹색 계열 오버레이로 분리되어야 한다
  - 학생이 앞쪽으로 퍼지는 방향을 읽을 수 있어야 한다
```

## 대표 시나리오별 권장 프롬프트

### 1. V자곡

```text
지형: V자곡
핵심 개념: 융기 후 하천의 하방 침식, 사면 조정, 깊어지는 계곡
필수 과정: 융기 -> 하천 침식 -> 사면 이동
카메라: 계곡 상류에서 하류를 향하는 정면 또는 약한 사선
반드시 보여줄 것:
- 바닥이 먼저 깊어지는 변화
- 양 사면이 따라 무너지는 변화
- 최종적으로 폭보다 깊이가 먼저 커지는 단면
학생용 질문:
왜 V자곡은 하천 바닥만 깎여서는 완성되지 않을까요?
```

### 2. 선상지

```text
지형: 선상지
핵심 개념: 산지 공급, 운반, 출구 감속, 부채꼴 퇴적
필수 과정: 풍화/공급 -> 운반 -> 퇴적
카메라: 분지 쪽에서 산지 출구를 바라보는 정면
반드시 보여줄 것:
- 산록 출구
- 유속 감소 지점
- 부채꼴로 퍼지는 퇴적 전면
학생용 질문:
왜 선상지는 산지 내부보다 산지 출구에서 뚜렷할까요?
```

### 3. 습곡 산지

```text
지형: 습곡 산지
핵심 개념: 압축, 습곡, 구조적 융기, 차별 침식
필수 과정: 압축 -> 습곡 -> 침식
카메라: 구조선이 길게 보이는 사선 시점
반드시 보여줄 것:
- 배사/향사 축
- 구조 골격 위에 생기는 능선과 골짜기
- 침식이 구조를 따라 다르게 나타나는 모습
학생용 질문:
습곡 산지의 모양은 습곡만으로 결정될까요, 침식도 함께 작용할까요?
```

## Geo-lab에서 바로 쓸 수 있는 제작 체크리스트

### 학생용 애니메이션 체크리스트

- 현재 단계가 `행동`으로 표현되는가
- 오버레이가 현재 단계의 핵심 과정 하나만 가리키는가
- 카메라가 지형 형성 방향을 숨기지 않는가
- 질문이 최종 모양이 아니라 과정 원인을 묻는가
- 같은 장면을 멈춰도 교사가 설명 가능한가

### 교사용 애니메이션 체크리스트

- 초기 장면과 현재 장면의 차이를 한 문장으로 설명할 수 있는가
- 우세 작용을 3개 이내로 요약할 수 있는가
- 학생이 흔히 오해하는 지점을 바로 짚을 수 있는가
- 결과를 말하기 전에 과정 순서를 말할 수 있는가

## 현재 Geo-lab의 수업 적합성 판단

현재 Geo-lab은 `교사 보조 시연 자료`로는 활용 가치가 있다. 다만 아래 조건이 충족되어야 한다.

- 시나리오별 카메라가 올바른 방향을 본다
- process overlay가 실제 우세 작용과 맞물린다
- 단계 캡션이 진행률이 아니라 과정 전환을 설명한다

아직 완전하지 않은 부분도 분명하다.

- 학생이 설명 없이 혼자 봐도 이해되는 수준은 아니다
- 일부 시나리오는 결과는 보이지만 원인-과정-결과 연결이 약하다
- 과정 오버레이와 교사용 설명 카드가 더 정교해져야 한다

따라서 현재 권장 사용 방식은 아래와 같다.

- 학생용: 교과서 개념 설명 직후 1차 시각화 자료
- 교사용: 설명 보조, 비교 질문 제시, 오개념 교정 자료
- 비권장: 학생 자율 학습용 무설명 애니메이션

## 다음 구현 우선순위

1. V자곡, 선상지, 습곡 산지 3개를 대표 수업 시나리오로 완성
2. 각 시나리오에 `과정 오버레이 1개 + 질문 1개 + 교사용 설명 포인트`를 고정
3. 교사 모드 GIF/export도 현재 단계 오버레이와 같은 메시지를 유지
4. 나머지 지형은 대표 3개 품질선에 맞춘 뒤 확장
