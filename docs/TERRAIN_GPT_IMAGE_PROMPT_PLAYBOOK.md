# Geo-lab GPT Image 지형 애니메이션 프롬프트 플레이북
이 문서는 Geo-lab의 고등학교 지형 애니메이션을 `gpt-image-2` 계열 이미지 생성으로 확장하기 위한 제작 기준이다. 목적은 학생이 최종 지형의 모양만 보지 않고, `내적 작용 -> 외적 작용 -> 대표 형상`의 순서를 이미지와 애니메이션으로 읽게 하는 것이다.

## 기준 자료

- `app/utils/high_school_world_geography.py`
- `docs/HIGH_SCHOOL_TERRAIN_ANIMATION_GUIDE.md`
- `docs/HIGH_SCHOOL_TERRAIN_ANIMATION_COMMANDS.yaml`
- `docs/TERRAIN_REFERENCE_NOTES.md`
- `docs/TERRAIN_REFERENCE_VALIDATION.md`
- `01_River_Landforms_Spec.md` ~ `07_Plain_Landforms_Spec.md`

OpenAI 공식 문서 기준으로 Image API의 이미지 모델명은 `gpt-image-2`다. Responses API의 hosted image generation tool을 쓸 때는 `gpt-5.4` 같은 텍스트 모델이 도구를 호출하고, 실제 이미지 생성 과정에는 GPT Image 모델이 사용된다.

참고:
- https://developers.openai.com/api/docs/guides/image-generation
- https://developers.openai.com/api/docs/guides/tools-image-generation

## 공통 제작 문법

모든 지형 이미지는 기본적으로 `4패널 교육용 인포그래픽`으로 만든다. 4패널은 그대로 애니메이션 키프레임이 되며, 이후 프레임 보간이나 짧은 GIF/MP4 제작의 기준 장면이 된다.

```text
Use case: infographic-diagram
Asset type: high-school terrain formation storyboard
Primary request: {지형명}의 형성 과정을 4패널 교육용 인포그래픽으로 표현
Audience: 고등학생, 처음 배우는 수준
Style/medium: 사실적인 교과서식 3D 지형 모식도, 과장된 만화풍 금지
Composition/framing: 같은 카메라 시점 유지, 패널 1-4가 왼쪽에서 오른쪽으로 진행
Process rule: 단계마다 우세 작용 1개만 강조
Overlay rule: 단계마다 오버레이 1개만 사용
Text: 짧은 한국어 라벨만 사용, 긴 문장 금지
Constraints: 지형 형성 방향이 보여야 함, 핵심 지형 요소가 잘리지 않아야 함
Avoid: 장식적 배경, 불필요한 도시/인물, 오개념을 만드는 과장된 형태
```

## 오버레이 규칙

Geo-lab의 기존 렌더러 팔레트와 맞추기 위해 아래 규칙을 고정한다.

| overlay | 의미 | 색상 방향 | 쓰는 장면 |
| --- | --- | --- | --- |
| `tectonic` | 내적 작용 | 주황/적색 | 융기, 침강, 압축, 습곡, 마그마 공급 |
| `erosion` | 외적 침식 | 청색 | 하방 침식, 측방 침식, 빙하 침식, 파랑 침식, 용식 |
| `transport` | 외적 운반 | 황색/주황 | 하천 운반, 모래 이동, 조석 혼합, 빙하 이동 |
| `deposition` | 외적 퇴적 | 녹색 | 선상지, 삼각주, 사주, 염류 침전, 사구 성장 |
| `change` | 전후 변화 | 회색 | 최종 정리, 형태 비교, 후퇴/확대 누적 |

## 제작 품질선

- 한 지형은 4단계 이내로 제한한다.
- 단계 제목은 명사보다 동사형으로 잡는다.
- 학생용 장면은 하나의 질문에 답해야 한다.
- 교사용 장면은 "왜 이 단계에서 이 작용이 우세한가"를 설명할 수 있어야 한다.
- 내적 작용이 직접 원인이 아니면 `간접/조건`으로 명시한다.
- 외적 작용은 풍화, 침식, 운반, 퇴적, 용식, 파랑, 빙하, 바람, 조석처럼 실제 작용명으로 쓴다.

## 지형별 프롬프트 카드

### `v_valley` V자곡

- 학습목표: 하천의 하방 침식과 사면 조정이 함께 작용해 깊고 좁은 V자곡이 만들어진다는 점을 이해한다.
- 내적 작용: 간접/조건. 지반 융기와 경사 증대가 하천 침식을 강하게 만드는 배경이 된다.
- 외적 작용: 하천 하방 침식, 사면 붕괴, 사면 이동, 반복 침식.
- 4단계: 융기와 경사 형성 -> 하방 침식이 깊어짐 -> 사면이 무너짐 -> V자곡이 완성됨.
- GPT Image 프롬프트: `4패널 가로 구성, 사실적인 고등학교 지형 수업용 인포그래픽, 같은 시점 유지. 패널 1은 융기된 좁은 계곡과 하천, 패널 2는 바닥을 깊게 깎는 하방 침식 화살표, 패널 3은 양옆 사면 붕괴와 사면 이동, 패널 4는 깊고 좁은 V자곡 단면 완성. 얇은 한국어 라벨, 절제된 침식 오버레이, 과장된 만화풍 금지.`
- 오개념 방지: V자곡을 빙하 지형으로 혼동하지 않게 한다. 측방 침식이 주된 원인처럼 보이지 않게 한다.

### `waterfall` 폭포

- 학습목표: 지층 차이와 차별 침식 때문에 폭포가 생기고, 두부 침식으로 상류 쪽으로 후퇴한다는 점을 이해한다.
- 내적 작용: 간접/조건. 단단한 층과 약한 층의 지층 차, 급경사 지형이 폭포 형성 조건이 된다.
- 외적 작용: 차별 침식, 두부 침식, 낙차 확대, 폭포 아래 소와 협곡 발달.
- 4단계: 지층 경사 차가 드러남 -> 약한 층이 먼저 깎임 -> 폭포가 상류로 물러남 -> 소와 협곡이 커짐.
- GPT Image 프롬프트: `4패널 가로 구성, 사실적인 지형 교육 이미지. 패널 1은 단단한 층과 약한 층이 만나는 하천 단면, 패널 2는 약한 층이 먼저 깎여 낙차 생성, 패널 3은 폭포 절벽이 상류로 후퇴, 패널 4는 아래쪽 소와 좁은 협곡이 발달한 장면. 같은 카메라 각도, 짧은 한국어 라벨, 화살표 중심, 과도한 물보라 연출 금지.`
- 오개념 방지: 폭포 위치가 고정된 것으로 보이지 않게 한다. 낙차만 있으면 무조건 폭포가 된다는 식으로 표현하지 않는다.

### `alluvial_fan` 선상지

- 학습목표: 산지 출구에서 유속이 줄어들며 물질이 부채꼴로 쌓여 선상지가 만들어진다는 점을 이해한다.
- 내적 작용: 간접/조건. 산지와 평지가 만나는 급격한 경사 변화가 퇴적 조건을 만든다.
- 외적 작용: 풍화 물질 공급, 하천 운반, 산지 출구 감속, 분산 퇴적, 부채꼴 확산.
- 4단계: 산지에서 물질이 내려옴 -> 좁은 골짜기에서 실려감 -> 출구에서 속도가 꺾임 -> 부채꼴 퇴적이 펼쳐짐.
- GPT Image 프롬프트: `4패널 가로 구성, 사실적인 산지-분지 경계 교육 인포그래픽. 패널 1은 산지 사면에서 자갈과 모래가 공급됨, 패널 2는 좁은 골짜기를 따라 운반됨, 패널 3은 산지 출구에서 급격히 감속하며 퇴적 시작, 패널 4는 바깥쪽으로 퍼지는 부채꼴 선상지 완성. 분지 쪽에서 산지 출구를 바라보는 시점, 얇은 한국어 라벨, 굵은 자갈에서 고운 물질로의 분급을 은근히 표시.`
- 오개념 방지: 선상지를 침식 지형처럼 보이지 않게 한다. 산지 내부가 아니라 산지 출구가 핵심임을 보인다.

### `braided_river` 망상하천

- 학습목표: 운반물이 많을 때 하도가 여러 갈래로 갈라졌다 합쳐지며 망상하천이 만들어진다는 점을 이해한다.
- 내적 작용: 간접/조건. 큰 유량 변동, 급경사, 많은 쇄설물 공급이 불안정한 하도 조건을 만든다.
- 외적 작용: 운반물 과잉 공급, 사주 형성, 하도 분기와 합류, 망상 구조 반복.
- 4단계: 퇴적물이 과잉 공급됨 -> 하도가 여러 갈래로 갈라짐 -> 가운데 사주가 솟음 -> 분기와 합류가 반복됨.
- GPT Image 프롬프트: `4패널 가로 구성, 사실적인 하상 지형 수업용 이미지. 패널 1은 자갈과 모래가 많은 하천, 패널 2는 한 줄 수로가 여러 갈래로 나뉨, 패널 3은 가운데 사주가 생겨 흐름을 나눔, 패널 4는 갈라졌다 합쳐지는 망상 구조가 반복되는 평면도. 평면 시점 유지, 짧은 한국어 라벨, 분기 화살표 명확, 장식적 요소 최소화.`
- 오개념 방지: 망상하천을 곡류하천의 한 종류처럼 보이지 않게 한다. 물이 적어서 갈라지는 것으로 표현하지 않는다.

### `free_meander` 곡류하천

- 학습목표: 곡류하천에서는 바깥쪽 침식과 안쪽 퇴적이 함께 일어나 굽이가 커지고 하도가 옆으로 이동한다는 점을 이해한다.
- 내적 작용: 간접/조건. 완만한 경사와 넓은 범람원이 곡류 발달 조건이 된다.
- 외적 작용: 측방 침식, 안쪽 퇴적, 하도 이동, 굽이 확장.
- 4단계: 작은 굽이가 생김 -> 바깥쪽이 깎임 -> 안쪽에 퇴적이 쌓임 -> 굽이가 옆으로 이동함.
- GPT Image 프롬프트: `4패널 가로 구성, 사실적인 곡류하천 교육 이미지. 패널 1은 완만한 평지에서 작은 곡류 시작, 패널 2는 바깥쪽 제방의 침식 강조, 패널 3은 안쪽 사주와 퇴적 강조, 패널 4는 굽이가 커지고 옆으로 이동한 최종 곡류. 같은 평면 시점 유지, 침식과 퇴적을 다른 색 오버레이로 비교, 짧은 한국어 라벨.`
- 오개념 방지: 곡류하천이 단순히 느려서 생긴다고 보이지 않게 한다. 안쪽과 바깥쪽이 같은 방식으로 변하지 않음을 보인다.

### `delta` 삼각주

- 학습목표: 강이 바다나 호수에 들어가며 유속이 줄어들 때 하구 앞쪽에 퇴적이 전진해 삼각주가 성장한다는 점을 이해한다.
- 내적 작용: 간접/조건. 해수면 정체, 약한 침강, 정체수역 조건이 삼각주 발달을 돕는다.
- 외적 작용: 하구 감속, 전면 퇴적, 분류 하천 발달, 바다 쪽 전진.
- 4단계: 하구에서 물이 느려짐 -> 전면 퇴적이 시작됨 -> 수로가 갈라짐 -> 삼각주가 바다 쪽으로 자람.
- GPT Image 프롬프트: `4패널 가로 구성, 사실적인 하구 지형 교육 인포그래픽. 패널 1은 강이 바다를 만나며 느려지는 장면, 패널 2는 하구 전면부 퇴적 시작, 패널 3은 여러 분류 하천이 갈라짐, 패널 4는 바다 쪽으로 전진한 삼각주 완성. 위에서 본 평면 중심, 조석과 파랑은 배경 수준으로만 표시, 짧은 한국어 라벨, 과도한 도시 배경 금지.`
- 오개념 방지: 삼각주를 하천 혼자 만드는 것으로 보이지 않게 한다. 감속과 퇴적의 관계를 생략하지 않는다.

### `bird_foot_delta` 조족삼각주

- 학습목표: 하천 공급이 매우 강하고 파랑 영향이 약할 때 분류 하천이 길게 뻗어 새 발 모양 삼각주가 만들어진다는 점을 이해한다.
- 내적 작용: 간접/조건. 하천 공급 우세, 약한 파랑과 조석 조건이 길게 뻗는 전면을 돕는다.
- 외적 작용: 하구 퇴적, 분류 하천 전진, 길고 좁은 수로 발달.
- 4단계: 퇴적이 하구에 몰림 -> 분류 하천이 뚫림 -> 길게 뻗는 수로가 생김 -> 새발 모양이 완성됨.
- GPT Image 프롬프트: `4패널 가로 구성, 사실적인 삼각주 비교 교육 이미지. 패널 1은 하구 전면에 퇴적물 집중, 패널 2는 수로가 분기되며 전진, 패널 3은 길고 좁은 분류 하천이 바다로 뻗음, 패널 4는 새 발 모양의 조족삼각주 완성. 평면도 유지, 길게 뻗는 수로 강조, 짧은 한국어 라벨, 둥근 호상 전면 금지.`
- 오개념 방지: 모든 삼각주가 둥근 호상 형태라고 보이지 않게 한다. 강한 파랑이 조족삼각주를 만든다는 인상을 피한다.

### `arcuate_delta` 호상삼각주

- 학습목표: 하천 퇴적이 진행되지만 파랑 재가공이 함께 작용하면 전면이 둥글게 휘는 호상삼각주가 된다는 점을 이해한다.
- 내적 작용: 간접/조건. 해안선의 파랑 에너지와 하구 조건이 전면 모양을 조정한다.
- 외적 작용: 하구 퇴적, 파랑 재가공, 가장자리 정리, 둥근 전면 발달.
- 4단계: 하구 퇴적 전면이 생김 -> 파랑이 가장자리를 다듬음 -> 전면이 둥글게 휘어짐 -> 호상삼각주가 완성됨.
- GPT Image 프롬프트: `4패널 가로 구성, 사실적인 해안 퇴적 지형 교육 이미지. 패널 1은 하구 앞 전면 퇴적 시작, 패널 2는 파랑이 양끝을 부드럽게 다듬음, 패널 3은 전면이 점점 둥글게 휘어짐, 패널 4는 호 모양의 호상삼각주 완성. 같은 평면도, 파랑 작용은 얇은 화살표로만 표시, 짧은 한국어 라벨, 새발 모양 과장 금지.`
- 오개념 방지: 호상삼각주를 하천 공급만의 결과로 보이지 않게 한다. 둥근 전면과 파랑 재가공의 관계를 보여준다.

### `cuspate_delta` 첨두삼각주

- 학습목표: 파랑의 재가공이 특히 강하면 삼각주 전면이 중앙으로 모이며 뾰족한 첨두삼각주가 된다는 점을 이해한다.
