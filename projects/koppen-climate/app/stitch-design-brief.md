# Stitch Design Brief

## Product
Standalone educational web app for learning Koppen climate classification.

## Audience
High school students.

## Core Goal
Help students understand not just the final climate code, but why a place becomes that code through latitude, circulation, seasonality, continentality, mountains, rain shadow, foehn, and monsoon effects.

## Design Direction
- Feel like an interactive geography lab, not a generic dashboard.
- Warm paper/beige background with deep teal panels.
- No purple bias.
- Strong visual hierarchy, bold but readable.
- Clean enough for class use, but visually memorable.
- Mobile and desktop both need to work.

## Main Experience
One page application with four major areas:

1. World climate map
- Large world map as the primary visual anchor.
- Colored climate overlay on top of a recognizable world map.
- Clickable spotlight regions.
- Overlay modes: Koppen, temperature, precipitation.

2. Guided learning panel
- Step-by-step mission cards for:
  - latitude and insolation
  - ITCZ and circulation
  - continentality
  - mountains, rain shadow, foehn
  - monsoon seasonality
  - reading Koppen letters
- Should feel instructional, not just informational.

3. Probe / selected location analysis
- Selected region title and coordinates.
- Koppen code badge.
- Short explanation sentence.
- Letter-by-letter Koppen decoding.
- Monthly temperature and precipitation graph.
- Driver panels showing why temperature and precipitation change.

4. Mountain transect / cause-effect section
- Visual cross-section for mountain uplift, rain shadow, and foehn.
- Should make topographic climate effects easy to understand.

## Required Components
- Hero section with short value proposition.
- Left control rail with simple sliders and toggles.
- Large map panel.
- Guided mission panel.
- Probe analysis panel.
- Climate graph.
- Rule trace / reasoning cards.
- Mountain transect panel.

## UX Rules
- Controls must stay simple.
- Explanations must be explicit.
- Every interaction should help answer:
  - where is this?
  - what climate is it?
  - why did it become that code?
- Avoid cluttered admin-dashboard patterns.

## Visual Notes
- Use a world-atlas / field-notebook mood.
- Panels can feel layered, like cards on a desk.
- Use subtle texture, gradients, and contour-like accents if helpful.
- Typography should feel intentional, not default SaaS.

## Output Request
Design a responsive single-page web app layout for this product.
Focus on high-level composition, panel hierarchy, and educational clarity.
Prefer a strong first-screen composition centered on the world map.
